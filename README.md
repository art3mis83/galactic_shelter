# 🌌 Galactic Shelter

**Galactic Shelter** est une application web permettant d’adopter des créatures extraterrestres selon leur rareté, dangerosité et pouvoirs.  
Elle sert de support pratique à un module de formation sur la **stratégie de test logicielle** et l’**automatisation de la qualité logicielle** (tests unitaires, intégration, API, E2E, performance, CI/CD).
